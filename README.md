# 발표자료 웹앱

슬라이드를 넣고 올리면 **발표용 웹앱이 자동으로 만들어집니다.** 참석자는 QR을 찍어 자기 휴대폰으로 같은 자료를 봅니다.

- 라이브: https://tigerjk9.github.io/my-slides/
- 설치할 것 없음. Node만 있으면 `node build.js` 한 줄로 돕니다.

## 무엇이 달라지나

발표 한 번 할 때마다 밟던 일곱 단계가 한 단계가 됩니다.

| | 전 | 후 |
|---|---|---|
| 슬라이드 만들기 | 파워포인트 | 그대로 |
| PDF로 내보내기 | 손으로 | — |
| 어딘가에 올리기 | 손으로 | — |
| 공유 페이지 만들기 | 손으로 | 자동 |
| 목차 정리하기 | 손으로 | 자동 |
| QR 만들기 | 손으로 | 자동 |
| 링크 나눠주기 | 손으로 | 주소 하나 |

## 쓰는 법

### 1. 슬라이드를 넣습니다

`slides/` 폴더에 HTML 파일을 번호 순으로 넣습니다.

```
slides/
├── 01-표지.html
├── 02-왜지금.html
└── 03-하루10분.html
```

제목은 파일 안의 `<h1>` 에서 가져옵니다. 없으면 `<title>`, 그것도 없으면 파일 이름을 씁니다.

### 2. 발표 정보를 적습니다

`deck.config.json` 한 파일만 고치면 됩니다. **동료 선생님은 이 파일만 바꾸면 자기 발표자료가 됩니다.**

```json
{
  "title": "우리 반 독서 습관 만들기",
  "subtitle": "학부모 설명회 자료",
  "speaker": "3학년 2반 담임",
  "date": "2026년 10월"
}
```

### 3. 만듭니다

```bash
node build.js
```

`index.html` 이 새로 만들어집니다. 브라우저로 열어 보십시오.

### 4. 올립니다

깃허브에 올리면 끝입니다. 그다음부터는 슬라이드를 고쳐 올릴 때마다 **GitHub Actions 가 알아서 다시 만듭니다.** 손으로 `node build.js` 를 돌릴 일이 없습니다.

## 발표할 때

| 조작 | 하는 일 |
|------|---------|
| `→` `Space` | 다음 슬라이드 |
| `←` | 이전 슬라이드 |
| `T` 또는 [목차] | 목차 열기 |
| [QR] | 참석자용 QR (이 페이지 주소가 담깁니다) |
| [전체화면] | 프로젝터용 |
| `Esc` | 목차·QR 닫기 |

휴대폰에서는 좌우로 밀어 넘깁니다.
